# keylab — 项目提案 v2

## 为什么做

程序员打代码的速度远慢于打普通文字，根本原因是括号、下划线、冒号等特殊符号在标准打字练习中几乎不出现。现有打字网站（Monkeytype、keybr）针对英文散文优化，对代码场景帮助有限。

keylab 的目标是成为**程序员的代码打字训练器**：通过主动输入真实算法实现，同时训练编程手速与算法肌肉记忆。对标 Monkeytype 的沉浸式打字体验，但所有内容都是真实的、有意义的代码。

## v2 核心升级方向

v1 完成了基础 MVP（打字引擎、成绩记录、排行榜）。v2 在此基础上做三件事：

1. **IDE 级打字体验**：语法高亮、行号、自动缩进、精准光标——让用户感觉在用真实编辑器。
2. **内容体系升级**：同一算法提供多语言 + 多风格 + 难度进阶变体，用户按自己的语言和水平选择。
3. **进度与激励系统**：连续打卡 Streak、成就徽章、系统学习路径与自定义收藏，让练习从一次性行为变成持续习惯。

## 给谁用

- **主要用户**：计算机专业学生，准备算法面试，希望提升代码打字速度
- **次要用户**：任何想提升代码手速的开发者
- **内容贡献者**：登录用户可投稿题目，经管理员审核后上线
- **管理员**：Supabase 管理员角色，负责内容审核和平台维护

## 成功标准

- 用户在 4 周内代码打字 WPM 提升 20% 以上
- 题库涵盖常见算法分类，每分类至少 3 道题，合计 50+ 变体
- 日活用户中 >50% 有连续打卡记录（Streak ≥ 3 天）
- 社区投稿渠道每月有有效投稿

## 不做什么（v2 明确排除）

- 不做代码执行和判题（不是 OJ，不需要沙箱）
- 不做自由作答（答案必须是预设文本之一）
- 不做团队/小组功能（留到 v3）
- 不做移动端适配
- 不做付费墙（全部功能免费）
- 不做视频教程或图文解释

## 技术约束

- 部署成本为零（Vercel 免费 + Supabase 免费 tier）
- 技术栈：Vue 3 + Supabase + Vercel，不引入新框架
- 代码不需要执行环境，纯前端渲染
